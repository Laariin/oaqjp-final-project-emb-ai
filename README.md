# Emotion Detection Application

## Project Overview
This project implements an AI-based Emotion Detection application using the Watson NLP library.

The application analyzes text input and identifies the emotions expressed in the text.

## Features
- Detects emotions from text using Watson NLP.
- Identifies anger, disgust, fear, joy, and sadness.
- Formats the emotion detection results.
- Handles errors and invalid input.
- Provides a web interface using Flask.
- Includes unit tests to validate the application.

## Technologies Used
- Python
- Watson NLP
- Flask
- Unittest
- PyLint

## Project Tasks
1. Clone the project repository.
2. Create the emotion detection application.
3. Format the output.
4. Package the application.
5. Run unit tests.
6. Deploy the application using Flask.
7. Implement error handling.
8. Perform static code analysis.
